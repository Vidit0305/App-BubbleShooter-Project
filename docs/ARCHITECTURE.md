# Architecture

Bubble Shooter is split into pure game logic, rendering, UI and services. The game logic has no widget dependencies and is covered by unit tests; the UI observes it.

```
            ┌──────────────┐  notifiers / repaint   ┌────────────────────┐
 input ───▶ │  GameEngine  │ ─────────────────────▶ │ GameBoard + Painter │
 (drag/tap) │  lib/game/   │                        │  ScorePanel, HUD    │
            └──────┬───────┘                        └────────────────────┘
                   │ GameSound events
                   ▼
            ┌──────────────┐        ┌────────────────────┐
            │ GameFeedback │ ─────▶ │ AudioService,      │
            │ lib/services │        │ haptics (Settings) │
            └──────────────┘        └────────────────────┘
```

## Folder layout

```
lib/
  main.dart                     Bootstrap: portrait lock, storage, audio, runApp
  app.dart                      Root widget: theme, home, lifecycle (music)
  game/                         Pure game logic (no widgets)
    game_config.dart            Tuning: speeds, shots per row, starting rows…
    bubble_color.dart           The six colors and their shades
    bubble.dart                 GridCell, FlyingBubble (trail, rainbow flag)
    bubble_grid.dart            Honeycomb grid: rows/cols, neighbors, row insertion
    board_layout.dart           Screen <-> world mapping, column count, danger line
    bubble_shooter.dart         Aim (clamped above horizontal), current/next bubbles
    collision_detector.dart     Sub-stepped movement, wall bounce, hits, snap cell
    trajectory_calculator.dart  Aim preview using the same physics as real shots
    match_finder.dart           BFS same-color groups and floating bubbles
    scoring.dart                Points, streak multiplier, praise tiers
    game_effects.dart           Pops, falls, particles, shockwaves, confetti, banners
    game_engine.dart            Rules, phases, streaks, rainbow, new rows, levels
  painters/
    bubble_painter.dart         Glossy bubble and rainbow bubble (cached shaders)
    brand_painter.dart          Glass bubbles + emblem shared by the icon and logo
    game_painter.dart           Board, trajectory, launcher, trail, effects, banners
  screens/                      home_screen, game_screen, settings_screen
  services/
    storage_service.dart        SharedPreferences wrapper
    settings_controller.dart    Settings, best score, haptics (ChangeNotifier)
    audio_service.dart          audioplayers, low-latency effects, music loop
    game_feedback.dart          Maps engine events to sounds and haptics
  theme/app_theme.dart          Indigo palette, text styles, glass panel
  widgets/
    game_board.dart             Playfield: input, painter, launcher HUD, sizing
    common/                     Buttons, PLAY button, page transition, background
    hud/                        Score panel (combo badge), next-bubble preview
    overlays/                   Pause, game over, level banner, confetti, card
assets/sounds/                  Generated WAV effects and music loop
branding/                       Icon masters (1024, Play Store 512, adaptive)
tool/                           Sound and icon generators
test/
  game/                         Logic unit tests
  services/                     Settings, storage, feedback unit tests
  widget/                       Screen and layout widget tests
```

## Key decisions

- **World units.** Game logic uses a coordinate space where the bubble radius is 1. `BoardLayout` picks the column count from the screen width (about 40 px per bubble, 8–12 columns, more on very short screens) and scales the world to the board, so every screen size plays the same.
- **Grid model.** Rows alternate between full rows and rows shifted by one radius with one bubble fewer. Pushing a row in at the top flips the row parity, so existing bubbles keep their positions.
- **Physics.** Shots advance in fixed 0.25-unit sub-steps carried across frames. This makes movement independent of frame rate, rules out tunneling, and makes the trajectory preview (same stepping) land in exactly the same cell as the real shot.
- **Rendering.** `GamePainter` repaints from the engine's `ChangeNotifier`, so the game loop never rebuilds widgets. HUD values are `ValueNotifier`s. Bubble shaders are created once per color. Text in the painter receives the theme font explicitly.
- **Lifecycle.** Pausing stops the ticker, and the game pauses automatically when the app goes inactive or hidden. Music is suspended in the background.
- **Assets from code.** The sounds, the music and the launcher icons are generated by scripts in `tool/`, so they can be tweaked and regenerated without third-party files.
